# circuit-simulator
A Python based DC circuit simulator designed to analyze electrical circuits and calculate their electrical properties.

# project-goals
* Simulate DC circuits
* Calculate voltage, current, resistance, and power
* Support series and parallel circuits
* Implement nodal analysis
* Eventually provide a graphical circuit-building interface

# technologies
* Python

# development-status
in development: currently developing component representation and circuit modeling system

# future-features
* Capacitors and inductors
* Diodes and transistors
* Ac circuit analysis
* Graphical interface
* Circuit visualization
